## v0.64 — Logging-Free Release

[Browse the v0.64 files](v0.64/) or open the [GitHub release page](https://github.com/joesnose/joesnose_nods_free/releases/tag/v0.64).

The release includes the standalone `joesnose_nods_free.prx`, installation ZIP, source ZIP, controls template, ARK entries and checksums. See [v0.64/CONTENTS.md](v0.64/CONTENTS.md) for the file descriptions.

Follow the [current installation instructions](../README.md#installation), update both ARK entries to the renamed PRX and preserve your existing controls and pairing files.
